## Перевірка коректності

### Властивості Max-Heap
Для кожного вузла i (крім кореня):
- arr[Parent(i)] >= arr[i]

### Властивості Min-Heap
Для кожного вузла i (крім кореня):
- arr[Parent(i)] <= arr[i]

### Перевірка після HeapSort
- Для сортування за зростанням: arr[i] <= arr[i+1] для всіх i
- Для сортування за спаданням: arr[i] >= arr[i+1] для всіх i

## Додаткові тести
