## Функціональність

### Частина 1: Побудова піраміди та пірамідальне сортування

**Функції бібліотеки Heap:**

1. **Навігація по піраміді:**
   - `Parent(i)` - індекс батьківського вузла
   - `Left(i)` - індекс лівого нащадка
   - `Right(i)` - індекс правого нащадка

2. **Незростаюча піраміда (Max-Heap):**
   - `MaxHeapify(arr, heapSize, i)` - підтримка властивості max-heap
   - `BuildMaxHeap(arr, n)` - побудова max-heap з масиву

3. **Неспадна піраміда (Min-Heap):**
   - `MinHeapify(arr, heapSize, i)` - підтримка властивості min-heap
   - `BuildMinHeap(arr, n)` - побудова min-heap з масиву

4. **Сортування:**
   - `HeapSort(arr, n, ascending)` - пірамідальне сортування
     - `ascending = true` - сортування за зростанням
     - `ascending = false` - сортування за спаданням

**Меню Lab_05_01:**
1. Ввести новий масив
2. Показати поточний масив
3. Побудувати незростаючу піраміду (Max-Heap)
4. Побудувати неспадну піраміду (Min-Heap)
5. Сортувати за зростанням
6. Сортувати за спаданням
7. Показати піраміду (візуалізація)
0. Вихід

### Частина 2: Черга з пріоритетами

**Функції для Max-Heap черги:**
- `HeapMax(arr, heapSize)` - повернути максимальний елемент
- `HeapExtractMax(arr, heapSize)` - видалити і повернути максимум
- `HeapIncreaseKey(arr, i, key)` - збільшити значення елемента
- `MaxHeapInsert(arr, heapSize, key, maxSize)` - додати новий елемент

**Функції для Min-Heap черги:**
- `HeapMin(arr, heapSize)` - повернути мінімальний елемент
- `HeapExtractMin(arr, heapSize)` - видалити і повернути мінімум
- `HeapDecreaseKey(arr, i, key)` - зменшити значення елемента
- `MinHeapInsert(arr, heapSize, key, maxSize)` - додати новий елемент

**Меню Lab_05_02:**
1. Ввести новий масив
2. Показати поточну чергу
3. Побудувати Max-Heap
4. Побудувати Min-Heap
5. Показати максимум (Max-Heap)
6. Видалити максимум (Max-Heap)
7. Збільшити ключ елемента (Max-Heap)
8. Додати елемент у Max-Heap
9. Показати мінімум (Min-Heap)
10. Видалити мінімум (Min-Heap)
11. Зменшити ключ елемента (Min-Heap)
12. Додати елемент у Min-Heap
0. Вихід

## Приклади використання

### Приклад 1: Побудова Max-Heap та сортування

```
Вхідний масив: [4, 10, 3, 5, 1]

1. Побудова Max-Heap: [10, 5, 3, 4, 1]
   Структура:
          10
         /  \
        5    3
       / \
      4   1

2. Сортування за зростанням: [1, 3, 4, 5, 10]
```

### Приклад 2: Черга з пріоритетами (Max-Heap)

```
Початковий масив: [16, 14, 10, 8, 7, 9, 3, 2, 4, 1]

Побудова Max-Heap: [16, 14, 10, 8, 7, 9, 3, 2, 4, 1]

Операції:
- HeapMax() → 16
- HeapExtractMax() → 16, черга: [14, 8, 10, 4, 7, 9, 3, 2, 1]
- MaxHeapInsert(15) → черга: [15, 14, 10, 8, 7, 9, 3, 2, 4, 1]
- HeapIncreaseKey(8, 20) → черга: [20, 15, 10, 14, 7, 9, 3, 2, 4, 1]
```

### Приклад 3: Черга з пріоритетами (Min-Heap)

```
Початковий масив: [5, 3, 8, 1, 9, 2]

Побудова Min-Heap: [1, 3, 2, 5, 9, 8]

Операції:
- HeapMin() → 1
- HeapExtractMin() → 1, черга: [2, 3, 8, 5, 9]
- MinHeapInsert(4) → черга: [2, 3, 4, 5, 9, 8]
- HeapDecreaseKey(3, 0) → черга: [0, 3, 2, 5, 9, 8]
```

## Обробка помилок

Програма містить обробку наступних помилок:

1. **Помилка введення даних**: перевірка коректності введених значень
2. **Порожня черга**: виняток `underflow_error` при спробі видалити з порожньої черги
3. **Переповнена черга**: виняток `overflow_error` при додаванні в повну чергу
4. **Невірна зміна ключа**:
   - `HeapIncreaseKey`: виняток якщо новий ключ менший за поточний
   - `HeapDecreaseKey`: виняток якщо новий ключ більший за поточний

## Складність алгоритмів

| Операція | Складність |
|----------|-----------|
| BuildMaxHeap / BuildMinHeap | O(n) |
| MaxHeapify / MinHeapify | O(log n) |
| HeapSort | O(n log n) |
| HeapMax / HeapMin | O(1) |
| HeapExtractMax / HeapExtractMin | O(log n) |
| HeapIncreaseKey / HeapDecreaseKey | O(log n) |
| MaxHeapInsert / MinHeapInsert | O(log n) |

## Особливості реалізації

1. **Індексація з нуля**: масив індексується з 0, тому:
   - `Parent(i) = (i-1)/2`
   - `Left(i) = 2*i + 1`
   - `Right(i) = 2*i + 2`

2. **Візуалізація**: функція `PrintHeap()` показує піраміду по рівнях для зручного аналізу структури

3. **Збереження оригіналу**: у Lab_05_01 при побудові піраміди створюється копія масиву, щоб зберегти оригінальні дані

4. **Гнучкість**: HeapSort підтримує як сортування за зростанням, так і за спаданням
