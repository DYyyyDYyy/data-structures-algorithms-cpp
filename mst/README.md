## Опис алгоритмів

### Алгоритм Краскала

**Принцип роботи:**
1. Сортує всі ребра графа за зростанням ваги
2. Використовує систему DSU (Disjoint Set Union) для відстеження з'єднаних компонент
3. Послідовно розглядає ребра у порядку зростання ваги
4. Додає ребро до каркасу, якщо воно з'єднує різні компоненти (не утворює цикл)

**Складність:** O(m log m), де m - кількість ребер

**DSU (Disjoint Set Union):**
- `set_make(v)` - створення множини з елемента v
- `set_find(v)` - пошук кореня множини, до якої належить v (з компресією шляху)
- `set_union(v1, v2)` - об'єднання множин (за рангом)

### Алгоритм Прима

**Принцип роботи:**
1. Починає з довільної вершини
2. На кожному кроці додає вершину, яка з'єднана з каркасом ребром мінімальної ваги
3. Використовує масиви:
   - `visited[]` - чи вершина вже в каркасі
   - `min_e[]` - мінімальна вага ребра до вершини
   - `sel_e[]` - вершина в каркасі, з якою з'єднано мінімальним ребром

**Складність:** O(n²) для матриці суміжності, O(m log n) з купою
